# TelemetryDualSenseAI project description

## Short description

An offline research prototype that converts official racing-game telemetry into custom, AI-assisted DualSense vibration feedback for accessibility and immersion.

## Repository description

TelemetryDualSenseAI records read-only telemetry from supported racing games, creates custom haptic labels from transparent rules, trains regression and CUDA deep-learning models, and plays predicted left/right USB DualSense vibration during offline driving. It never automates gameplay inputs, creates virtual controllers, reads arbitrary game memory, or captures native commercial-game haptics.

## Tagline

**Official telemetry in. Custom research haptics out.**
